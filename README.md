## Requirements and running an exercise

Install a Java Development Kit (JDK) that provides `javac` and `java`. Each exercise is a standalone source exercise; choose a `.java` file and compile/run it from its directory. For example:

```sh
cd Java_Basic_Questions
javac Question_1.java
java Question_1
```

For exercises declaring a Java package, compile with the package-aware output path and run using the fully qualified class name. Source names and class names vary by exercise; inspect the selected file before substituting them in the commands above.

## Notes

This is a collection of lab examples rather than one packaged application. No single root build configuration is provided.
